# 图像识别与目标检测选型

图像任务不适合与表格任务共用固定训练器。建议保持数据和输出约定，直接使用成熟工具：

- 图像分类：`timm` 预训练 ResNet/ConvNeXt，按类别目录组织 `train/val/test`。
- 目标检测或缺陷定位：Ultralytics YOLO，使用标准 YOLO 数据集 YAML。
- 小数据：优先迁移学习、强数据增强与分层交叉验证；报告逐类 Precision/Recall/F1 和混淆矩阵。
- 医学或工业数据：按患者、设备或批次分组切分，禁止同一来源同时进入训练集和测试集。

训练时把权重、配置、类别映射、随机种子与逐样本预测保存在 `outputs/<run_name>/`，以便复现并生成论文图表。
