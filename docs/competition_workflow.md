# 比赛工作流

1. 将原始附件复制到 `data/raw/`，运行 `mathmodel inspect` 检查缺失、重复和类型。
2. 明确预测对象、预测时点与可用特征；删除任何在预测时尚不可知的泄漏字段。
3. 先运行核心模型得到可信基线，再按需安装 boosting/时序/异常检测扩展。
4. 修改配置后保留不同的 `run_name`，以免覆盖实验。
5. 根据交叉验证均值选择模型，只用测试集做一次最终评估。
6. 将指标表、预测表和 SVG/PNG 图片写入论文，并说明数据切分、指标定义和随机种子。
7. 做特征删减、参数扰动或时间窗口变化实验，报告结论是否稳定。

模型复杂不等于建模质量高。比赛答卷应把数据依据、假设、变量的现实含义、误差来源和结论边界串成闭环。
